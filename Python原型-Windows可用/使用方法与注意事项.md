# ChronoVolume-原型程序 使用方法与注意事项

这份说明适用于 Windows 用户。这个文件夹里的是 ChronoVolume 的 Python 原型版本，可以在 Windows 上运行，用来体验视频时间体积、切片预览、参考面切片和基础导出等功能。

注意：这是 Python 原型程序，不是 macOS SwiftUI + Metal 正式版。正式版目前主要面向 macOS；这个原型版本是为了让 Windows 用户也能运行和体验核心思路。

## 文件说明

这个文件夹里主要有这些文件：

- `Start-ChronoVolume-Prototype-Setup.cmd`：双击启动安装助手。
- `ChronoVolumePrototypeSetupAssistant.ps1`：中文图形化安装助手，不需要预先安装 Python。
- `ChronoVolume-原型程序.py`：真正的 Python 原型程序。
- `requirements-chronovolume-prototype.txt`：程序需要安装的 Python 依赖列表。
- `README_WINDOWS_SETUP.md`：安装助手的简短说明。
- `使用方法与注意事项.md`：也就是当前这份更完整的使用说明。

## 推荐使用方式

1. 在 GitHub 仓库页面点击绿色 `Code` 按钮。
2. 选择 `Download ZIP` 下载整个项目。
3. 解压 ZIP 文件。
4. 进入 `Python原型-Windows可用` 文件夹。
5. 双击 `Start-ChronoVolume-Prototype-Setup.cmd`。
6. 在打开的中文窗口里点击 `完整安装/修复`。
7. 等待日志显示安装完成。
8. 点击 `运行程序`。

第一次运行需要联网下载 Python、FFmpeg 和 Python 依赖，时间可能比较长。后续再次运行通常只需要打开安装助手，然后点击 `运行程序`。

## 安装助手按钮说明

`完整安装/修复`

自动检查并安装 Python、FFmpeg、虚拟环境和程序依赖。第一次使用推荐直接点击这个按钮。

`检查状态`

检查当前电脑是否已经准备好运行环境。重点看这几项是否显示“已就绪”：

- Python
- FFmpeg
- `.venv`
- `PySide6 / OpenCV / NumPy`

`安装 Python`

只安装 Python。如果电脑已经有 Python，一般不用点。

`安装 FFmpeg`

只安装 FFmpeg。FFmpeg 用于提高视频读取兼容性，尤其是某些特殊编码或带透明通道的视频。

`安装依赖`

只安装 Python 依赖。若 `PySide6 / OpenCV / NumPy` 显示缺失，点击这个按钮。

`运行程序`

启动 `ChronoVolume-原型程序.py`。

`打开程序文件夹`

打开当前原型程序所在文件夹，方便查看日志或确认文件是否齐全。

## 程序基本使用流程

1. 点击程序里的导入视频按钮。
2. 选择一个视频文件。
3. 等待程序读取视频帧并生成体积数据。
4. 在 2D 视图中查看不同轴向的切片播放。
5. 在 3D 立方体视图中观察视频作为时间体积的形态。
6. 根据需要切换轴向、调整参考面、播放预览或导出当前视图。

建议第一次测试时使用较短、分辨率较低的视频，例如 5 到 20 秒、1080p 或更低。过长或过大的视频会占用更多内存，也会让读取和切片计算变慢。

导入视频时也可能出现短暂卡顿；如果卡顿时间过长，请检查程序是否已经显示“未响应”，必要时先换用更短或分辨率更低的视频测试。

## 常见问题

### 点击完整安装/修复后像是卡住了

第一次安装 `PySide6` 可能需要几分钟。只要运行日志仍在变化，就说明还在安装。请不要马上关闭窗口。

如果长时间完全没有新日志，可以关闭安装助手后重新打开，再点击 `检查状态`。如果依赖没有就绪，再点击 `安装依赖`。

### 点击运行程序后没有窗口

新版安装助手会生成启动日志：

`ChronoVolume-原型程序启动日志.txt`

这个文件会出现在 `ChronoVolume-原型程序.py` 同一个文件夹里。打开它可以看到程序启动失败的具体原因。

常见原因包括：

- 依赖没有安装完整。
- Python 虚拟环境被删除或移动。
- 文件夹路径里存在系统权限问题。
- Windows 安全软件拦截脚本运行。
- 视频相关库安装失败。

### Windows 提示脚本不安全或阻止运行

这个安装助手是本仓库中的本地脚本，用于安装运行环境和启动程序。如果 Windows Defender 或 SmartScreen 弹出提示，可以选择“更多信息”，然后选择继续运行。

如果公司或学校电脑限制 PowerShell 脚本，可能需要换个人电脑运行，或联系管理员开放脚本执行权限。

### 下载很慢或依赖安装失败

依赖需要从网络下载。如果网络不稳定，可能会失败。可以重新点击 `安装依赖`。如果多次失败，建议切换网络后再试。

### FFmpeg 安装失败

安装助手会优先通过 Windows 的 `winget` 安装 FFmpeg。如果电脑没有 `winget`，安装助手会打开 FFmpeg 下载页面。手动安装后，关闭安装助手并重新打开，再点击 `检查状态`。

### 视频导入失败

可以先尝试：

- 换一个常见格式的视频，例如 `.mp4`。
- 使用更短的视频测试。
- 避免文件路径过长。
- 确认 FFmpeg 状态显示“已就绪”。

## 注意事项

- 不要删除 `.venv` 文件夹，除非你准备重新点击 `完整安装/修复`。
- 不要只下载单个 `.py` 文件；推荐下载整个 `Python原型-Windows可用` 文件夹。
- 不要把程序放在需要管理员权限的系统目录里，例如 `C:\Windows` 或 `C:\Program Files`。
- 推荐放在桌面、下载目录、文档目录，或单独创建的普通文件夹里。
- 视频越大，占用内存越高；如果电脑内存较小，建议先用短视频测试。
- 预览可能会出现卡顿，尤其是 3D 视图。这通常和视频尺寸、帧数、电脑性能以及当前视图复杂度有关。
- 这是原型程序，性能和功能完整度不等同于 macOS 正式版。
- 原型程序的核心本体只有 `ChronoVolume-原型程序.py`。如果你想自行尝试修改，或暂时无法联系 UP 主，也可以把这个文件直接交给常用 AI 工具，说明你的需求并寻求修改帮助。
- 程序运行环境会安装在当前文件夹的 `.venv` 中，不会上传文件，也不会读取 GitHub token、密码或其他账号信息。

## 隐私说明

这个原型程序主要在本地读取用户选择的视频文件，并在本地进行计算和预览。安装助手只负责安装 Python、FFmpeg 和必要依赖，不会主动上传你的视频、项目文件或账号信息。

如果你要把运行后的文件夹再次上传到 GitHub，请不要上传这些内容：

- `.venv`
- `__pycache__`
- `ChronoVolume-原型程序启动日志.txt`
- 自己导入或导出的视频文件
- 任何包含个人路径、账号、密钥或私人素材的文件

## 适合反馈的问题

如果程序无法运行，反馈时建议提供：

- Windows 版本。
- 安装助手里哪些状态显示“缺失”。
- `ChronoVolume-原型程序启动日志.txt` 的错误内容。
- 使用的视频格式和大致大小。
- 点击哪个按钮后出现问题。

这样更容易判断问题出在安装环境、依赖、视频格式，还是程序本身。
